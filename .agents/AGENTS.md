# CLARION CORPORATE WEBSITE MASTER PROMPT (Workspace Rule)

## Core Directive
- **Visual-first Technology Corporate Website**: VISUAL 70–80% / TEXT 20–30%.
- "이 내용을 글 대신 어떻게 보여줄 수 있는가?" (Visual diagram, architecture, motion, data flow).
- **Zero Payment Features**: Payment, checkout, order, cart, program purchase, or PG integrations are strictly forbidden on the Clarion Corporate Website.
- **Factuality First**: Never introduce fake revenue, unverified client logos, unreleased patents, or fake test counters.

## Brand Essence & Storytelling
- Philosophy: "사람을 이롭게 하는 기술, 책임 있게 성장하는 기업." / "Technology for People. Growth with Responsibility."
- Visual Brand Story: WAVE → ORDER → CONNECTION → INTELLIGENCE → HUMAN.
- 3-Tier Portfolio: NOW (Core Business) → NEXT (Growth Technology) → FUTURE (Healthcare Innovation).

## Section Rules
1. **Header**: Transparent/translucent on dark Hero, 95% white blur when scrolled. No dead links.
2. **Hero (Clarity Wave)**: Video fallback to WaveCanvas, left-aligned overlay gradient, exact brand headline ("복잡한 기술을, 명확한 실행으로.").
3. **About Clarion**: Large CEO Editorial Portrait, CEO Quote ("우리가 만드는 기술은 결국 누구를 향하고 있는가."), exact CEO Message, Value Chain Diagram.
4. **Core Business**: Enterprise Architecture Diagram (USER → FINANCIAL IT → ENTERPRISE SYSTEM → CLOUD & APPLICATION → DATA → SECURE OPERATION) with data flow.
5. **Growth Tech**: Deep Navy Space, "From Data to Action", SVG Data Flow Diagram, 6-step R&D Process Flow.
6. **Healthcare Innovation**: Warm White / Mint / Cyan space, "기술의 마지막은, 사람이어야 합니다.", Hansaeng AI User Journey, Mobile UI Mockup, PATENT PENDING IP visual.
7. **Contact**: B2B project inquiry form with enterprise categories.
